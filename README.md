# Balatro RU (Alternative)

Альтернативный русский перевод для [Balatro](https://www.playbalatro.com/). Мод заменяет встроенный русский язык на переработанный вариант со своим шрифтом.

## Требования

- [Balatro](https://store.steampowered.com/app/2379780/Balatro/)
- [Steamodded](https://github.com/Steamodded/smods) версии `1.*` или выше

## Установка

1. Установите Steamodded, следуя [официальной инструкции](https://github.com/Steamodded/smods/wiki).
2. Скачайте этот репозиторий (кнопка **Code → Download ZIP** или `git clone`).
3. Скопируйте папку мода в папку с модами Balatro:
   - **Windows:** `%AppData%\Balatro\Mods\`
   - **macOS:** `~/Library/Application Support/Balatro/Mods/`
   - **Linux (Steam/Proton):** `~/.local/share/Steam/steamapps/compatdata/2379780/pfx/drive_c/users/steamuser/AppData/Roaming/Balatro/Mods/`
   - **iOS / Android:** см. [инструкцию для мобильных устройств](https://docs.smods.dev/Installation/Installing%20Steamodded%20mobile/)
4. Запустите игру и выберите **«Русский»** в меню выбора языка.
